KEY DECISIONS RECORDED
  - Inline single <script type="module"> instead of js/ module files, because
    file:// blocks ES-module imports via CORS and the Definition of Done
    requires double-click execution. Documented in README.txt.
  - Inline tailwind.config for custom keyframes (CTA pulse, wave, shake,
    pop-in, float); custom CSS limited to @font-face, title text-stroke,
    scrollbar hiding.
  - WebAudio synthesized SFX instead of audio files (zero bytes, always
    available offline).
