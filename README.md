# Fish of Fortune — Lane Runner Reskin

A reskin of a simple HTML lane-runner into a "Fish of Fortune"-style casual game. Built with vanilla JS + Three.js (CDN) + Tailwind (CDN). No build step.

**Play it live:** open the GitHub Pages link of this repo, or just double-click `index.html` (runs from `file://`, fully self-contained).

## How to play
- Move: **← → / A / D** or **tap left/right half** of the screen (mobile).
- Catch coins (+1) and gems (+10 coins, +1 gem). Dodge sea urchins.
- Infinite run — score = coins collected; difficulty ramps over time.

## Key features to try
- **Portals** (bubble plumes sliding down the screen edges): swim in to warp or dodge them. First portal opens a pause-guide with screenshots.
  - **Purple** — Diamond rush: all coins become gems.
  - **Red** — Die or refresh: only fast bombs; exiting restores all energy.
  - **Gold** — Gold rush: only coins; collect 15 and a waterfall flushes you out.
- **Economy**: persistent wallet (starts at 100), 10 coins per run, energy as run-currency fallback (regen 1/45s), exponential urchin tax (2·2ⁿ).
- **Shop**: Shield (absorbs 1 hit, ×2 price), Grow (fish ×1.1 and +1 heart per level, ×2 price, max 5), Baby swarm (3 helper fish collect valuables for 15s, ×2 per use, countdown ring on the card).
- **Fish shop** (hamburger): 6 gem-priced fish — Lucky, Bubble, Toxic, Diamond, Devil, God — same body size so the armor fits all.
- **First-run guides**: tap-hand animation + portal guide (reset every reload).
- **CTA end card**: blurred scene + animated light rays, logo, pulsing Download button, your fish orbiting it. Shown after death, after gold rush, after a fish purchase.
- Volumetric-style light beams + caustics + per-level painted backgrounds; generative WebAudio music + SFX (no audio files).

## Project layout
- `index.html` — the whole game (single inline ES module; works over `file://`)
- `assets/` — WebP icons (generated by `assets/src/gen_icons.py`), font, backgrounds
- `glb/` — Part 2 models: `fish/` contains `fish.glb` + Blender source + prompts; **farm-house and character models were not created** (prompts/workflow docs included in their folders)
- `design/` — UI design targets, `docs/` — agent transcripts & session export
- `README.txt` — full workflow/time log, `Prompts.md` — summarized coding-agent prompts

## Notes
- Over `http(s)` the game loads `glb/fish/fish.glb` as the player model; over `file://` a procedural fallback fish is used (CORS).
- Everything except the two CDN libraries (Tailwind, Three.js) is local. Loaded payload ≈ 0.75 MB.
